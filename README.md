# Carbon Intensity Forecasting

A reproducible data-science demonstration using UK grid carbon-intensity data.

Start with [`notebooks/carbon_intensity_demo.ipynb`](notebooks/carbon_intensity_demo.ipynb)
to see API-shaped data ingestion, time-series feature engineering, a naive
baseline, a regression model, and time-ordered evaluation in one place.

The original workshop notebook is kept locally for reference but is ignored by
Git so the public repository presents my own applied analysis rather than a
teaching worksheet.
